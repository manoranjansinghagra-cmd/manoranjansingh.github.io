ASHUPRIYA4EVER SHOPPING PLATFORM
================================
Features:
- Premium animated background flash/glow
- Product search
- Category filters
- Product cards
- Wishlist demo
- Shopping cart with quantity controls
- LocalStorage cart persistence
- Checkout/customer form
- Demo order generation
- Newsletter form
- Mobile responsive design

IMPORTANT FOR REAL E-COMMERCE:
The front-end is functional, but real payment/order processing requires a secure backend and payment gateway (e.g. Razorpay/Stripe/PayPal), product database, inventory, shipping and admin panel.
